## 엑셀 일괄 등록과 거래처 번호 입력 (2026-10-14)

견적 관리, 거래처 관리, 소재 관리 화면의 **엑셀 … 일괄 등록** 버튼을 사용합니다.

1. **XLSX 양식 다운로드**를 누릅니다. `입력` 시트에 한 행당 한 품목/거래처/소재/매입처 단가를 작성합니다. `작성안내`와 현재 저장된 `참조ID` 시트를 함께 확인하세요.
2. 파일을 선택하고 **업로드 미리보기**를 누릅니다. 열 이름으로 연결하므로 열 순서는 변경할 수 있습니다. 모르는 열·빠진 필수 열은 오류입니다. 행별 오류와 중복, 수정 전후 값을 확인합니다. 이 단계와 취소는 업무 데이터를 저장하지 않습니다.
3. 저장할 행을 선택해 **저장 확정**을 누릅니다. 정상 신규 행은 기본 선택이며, 기존 기록은 `작업=수정`과 `기존ID`를 적고 미리보기에서 직접 선택한 다음 수정 승인을 체크해야 합니다. 선택하지 않은 행은 저장하지 않습니다.

견적은 별도 제품 마스터가 아니라 **현재 작성 중 수기 품목 + 선택한 엑셀 품목**을 합쳐 새 견적 1건으로 저장합니다. 합계 100품목까지이며, 작성 중인 불완전한 행은 먼저 완성하거나 제거하세요. 창 안의 거래처·납기·결제조건도 확인하세요. 저장 후 원래 입력은 화면에 남고, 저장된 견적 ID와 완료 상태로 연결됩니다. 일반 저장·엑셀 재등록은 차단됩니다. 입력을 수정해도 기존 견적은 자동 변경하지 않습니다. 저장된 견적 보기로 확인하거나, 이 입력으로 새 견적 작성에서 확인한 뒤 별도 견적을 작성하세요. 새 견적 전환은 현재 입력을 지우지 않습니다. 도면 첨부는 별도입니다. 거래처·소재·매입처별 단가는 한 파일당 1,000행까지 지원하며 미리보기는 50행씩 보여 줍니다.

파일은 `.xlsx`만, 최대 5 MiB입니다. `.xls`·`.xlsm`·CSV, 수식·매크로·외부 연결·병합 셀은 지원하지 않습니다. 로컬 서버에서 값만 읽으며 Excel을 실행하거나 외부 서비스로 보내지 않습니다. 날짜는 텍스트 `YYYY-MM-DD`, 번호·계좌·ID는 텍스트로 입력하세요. 숫자 셀로 변환되어 이미 사라진 앞자리 0은 추정하지 않고 오류로 안내합니다. 빈 선택 값은 미입력이고 0으로 바꾸지 않습니다. 수정 행의 빈 선택 값은 기존 값을 유지하며 일괄 비우기/삭제는 지원하지 않습니다. 기본 소재 단가는 원/kg, 매입처 단가는 열에 명시한 원/kg·원/개·원/m를 유지하고 자동 환산하지 않습니다.

중복 기준은 거래처명 또는 하이픈을 제외한 사업자번호, 재질명, 매입단가의 소재·매입처·형상·치수·단위·적용일 조합입니다. 견적 파일은 품목명·도면/버전·소재·형상·치수 조합으로 중복을 확인합니다. 미리보기 이후 다른 저장이 발생하면 재미리보기를 요구합니다. 선택 행 전체를 검증한 후 하나의 파일 교체로 저장합니다. 통신 결과가 불확실하면 **같은 요청 재시도**를 이용하세요. 동일 요청키는 재접속·서버 재시작 후에도 두 번 저장하지 않습니다. 또한 일반 저장과 엑셀 저장이 같은 작성 ID를 공유하여, 요청키나 입력값을 바꿔 다시 보내도 같은 작성 건에서 두 번째 견적을 만들지 않습니다. 미확정 미리보기는 서버 재시작 또는 30분 후 만료됩니다.
