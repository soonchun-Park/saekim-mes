# 새김 CI 디자인 검토 — 구현 및 적용 완료

초기 로컬 조사에서는 새김 자료가 없었다. 이후 사용자의 새김 CI 폴더에서 가로형 로고와 심볼 SVG를 확보해 렌더링 확인하고 원본 바이트를 그대로 사용했다. 출처와 해시는 reference/saekim-ci/README.md에 기록했다. GMS 및 타사 자산으로 대체하지 않았다.

## 확인한 UI 개선 범위

- 공통 기업용 스타일 위에 모듈별 파랑 계열, 테두리, 모서리, 버튼 높이가 다시 정의되어 있다. 공통 토큰과 우선순위를 정리해야 한다.
- 공통 화면 소개와 시험환경 안내가 반복되며, 좁은 화면에서 실제 업무 패널의 시작 위치가 지나치게 아래로 내려간다. 기능상 안내를 보존하면서 여백과 계층을 정돈한다.
- 대시보드의 모든 날짜 버튼과 업무 버튼이 동일한 강조를 받는다. 날짜 셀, 보기 전환, 주 동작을 구분한다.
- 견적·거래처·소재·정산 표의 머리글 배경, 테두리와 셀 여백을 통일한다. 숫자 우측 정렬과 표 내부 가로 스크롤은 보존한다.
- 등록 폼, 읽기 전용 값, 안내, 오류, 저장 상태를 색상과 문구로 함께 구분한다. 불필요한 필수 항목 추가 없이 필드 구조를 유지한다.
- 팝업의 높이 제한/스크롤과 중앙 위치를 유지하고 제목·동작부 여백을 맞춘다.
- 상단 정렬, 390px 모바일, 긴 한국어 문구, 키보드 포커스, 숫자 입력 커서, XLSX 미리보기 및 취소 동작을 회귀 검증한다.

## 범위 제한

화면 표현과 브랜드 표시만 수정했다. 데이터 스키마·업무 규칙·실제 사용자 자료·다른 서버·Google 연결 설정을 수정하지 않았다. 8791의 CSS·생성 HTML과 빌더에 반영했고 재시작하지 않았다. 발행된 견적·외주 문서의 거래 내용과 회사 정보는 이 디자인 변경의 대상이 아니다. 최종 결과는 qa/reports/design-final.json을 참고한다.
