# MES 로컬 협업 규칙

앱 코드 변경은 사용자 요청으로 중단 상태입니다. 현재 목적은 업무 규칙·원가 계산·사급/도급·부분처리·도면 REV·UX의 읽기 전용 검토입니다. 기존에 차단된 보안 검사를 위임하거나 우회하는 작업이 아닙니다.

원본 프로젝트는 그대로 유지하고 같은 로컬 Git 저장소의 두 worktree를 사용합니다. 버디 구현 공간은 buddy/implementation, Claude 검토 공간은 claude/review입니다. 원본의 data/·첨부 원본·자격증명·브라우저 프로필·QA 화면은 Git에 넣지 않습니다. 외부 remote/push와 자동 병합은 사용하지 않습니다.

검토 기준은 qa/review-freeze.json의44개 파일 SHA256 및 해당 파일들과 이 문서를 포함한 로컬 baseline commit입니다. 앱 소스는 동결 코드이며 협업 문서 추가는 기능 수정이 아닙니다. qa/checklist-review.json은 구현 결과와 미완료 방향 제안입니다. 제안 자체는 구현 승인이 아닙니다.

도면 UI는 staged이며 실제8788은 소재 미리보기입니다. 숫자 커서 수정은 적용/검증됐고 도면/REV는 별도 격리 Chrome에서 검증됐습니다. 최초 수주 확정과 현재 REV 분리, 문서별 처분, legacy품목 첨부 등 미완료 항목을 그대로 검토합니다. Google 연결/OAuth/배포·실제 발송·발주·결제는 승인되지 않았습니다.

검토자는 REVIEW_TEMPLATE.md에 기준commit/해시·작업범위·변경파일·시험·미확인·질문/답변·다음담당자를 기록합니다. 원본/서로의 branch를 덮거나reset하지 않습니다. 수정은 별도 사용자 승인 이후 담당자 branch에서만 수행하며 결과는 diff와 시험을 확인한 뒤 별도 결정합니다.

Claude Code의 기존 로그인은 현재 확인되지 않았습니다. 여기서 로그인/키 발급/요금 전환을 실행하지 않습니다. 코드·허구 사례·체크리스트의1회 검토 전송만 사용자 승인됐으며 실제 자료·도면·인증정보는 제외합니다. auth와기존요금범위가 확인되지 않으면 호출을 보류합니다.
