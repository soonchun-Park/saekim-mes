Selected after inspecting https://www.m3pn.com/main/ in an isolated Headless Chrome 155 on 2026-10-14. Computed CSS and actual rendered glyphs confirmed SUIT Regular for Korean body text and SUIT Bold for Korean headings. That site's decorative Latin hero uses Orbitron; the MES UI uses the Korean/body family SUIT throughout. No font files were copied from M3PN.

The integrated builder embeds the original WOFF2 and full license into its generated HTML. This keeps all font delivery on the local application and needs no CDN, operating-system font installation, new asset routes, or server restart. Document previews copy that embedded font face into their self-contained HTML, including the license; downloaded production documents retain the font offline. A system Korean sans-serif fallback remains available if font loading fails.

The original SAEKIM outlined SVG logo is unaffected.
